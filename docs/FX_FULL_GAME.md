# 麻将对局特效交付

本批素材位于 `assets/fx/full-game/`，沿用邮件与组队主参考的道家 Q 版手绘材质。8 个中文提示、24 张效果阶段帧、2 个无字结算装饰和 1 张可复用提示空底，共 35 项正式 PNG；另附六条无损 WebP 预览、深浅底联系图、锚点和 Aseprite JSON 图集。

## 资源与触发

| 类别 | 资源 | 使用方法 |
|---|---|---|
| 操作提示 | 吃、碰、杠、胡、听、自摸、流局、胜利 | `callouts/` 的768×512 RGBA，中心锚点(384,256)，整体等比显示；按真实规则/结果触发 |
| 提示空底 | `callout-base.png` | 与提示文字分离，便于字体本地化；不作九宫格拉伸 |
| 摸牌聚光 | `frames/draw-focus-00…03.png` | 400ms，单次，结束隐藏 |
| 出牌落光 | `frames/discard-impact-00…03.png` | 333ms，单次，结束隐藏 |
| 当前玩家 | `frames/player-ring-00…03.png` | 667ms循环，亮点顺时针经过上/右/下/左；切换行动玩家后隐藏旧光环 |
| 胡牌金云 | `frames/hu-burst-00…03.png` | 533ms，单次，结束隐藏 |
| 胜利彩纸 | `frames/victory-confetti-00…03.png` | 667ms，单次，结束隐藏 |
| 奖励星辉 | `frames/reward-stars-00…03.png` | 600ms，单次，结束隐藏 |
| 无字结算装饰 | `settlement-defeat.png`、`settlement-draw.png` | 512×512 RGBA，分别为低垂绢带与平衡玉云；文字由客户端覆盖 |

六类帧统一512×512画布、中心锚点(256,256)，推荐画布按实际界面等比显示；有效图形通常约100—300px，是保留透明边距的导出画布，并不宣称有原生512px的细节。不得逐帧单独适配包围盒，否则会破坏扩散大小与注册。

`timelines.json` 提供精确整数毫秒、60Hz节拍、是否循环、结束隐藏及可选33ms阶段淡化与80ms结束淡出。四张阶段是实际生成的不同画面；淡化仅是运行时补间，不是额外模型生成帧、连续视频或角色骨骼动画。`animation-clips.json` 为可直接解析的逐帧时序，帧路径相对本文件。一次效果结束后应移除节点，不能把最后一帧长期留在牌桌。

## 图集和透明度

`engine/aseprite/mahjong-fx.json` 和同目录 PNG 为24帧图集，含六个 frameTags、精确时长、事件与中心锚点；`engine/engine-export.json` 包含坐标映射及逐帧RGBA回读校验。导入采用线性采样、正确直通/预乘 Alpha 设置，避免不受控纹理压缩。图集已有透明间距与1px外扩，不把同页相邻格混入素材。

帧是四格原生1254×1254图集的派生切片，单格627×627，经原生Alpha清理、同一缩放和透明补边导出。提示空底原生1536×1024；结算装饰原生1774×887双格。尺寸均记录实际返回值，未放大冒称高清。为修正生成器在格内的中心偏移，部分帧按光核、落牌环中心或头像环内孔做整数平移；每类的缩放比例保持一致，具体值在逐图记录。

Alpha清理只移除1—4级近不可见底雾以及不连接真实图形的微弱杂点，保留柔光。原始图集的 `safe_frame` 和 `faint_specks` 建议已由导出留白与清理处理。深浅底最终联系图位于 `previews/frames-alpha.png`、`previews/callouts-alpha.png`。

## 中文、来源与验收

八种提示文字采用本机楷体准确排版，生成的是无字手绘底板。字形排版、颜色与尺寸在对应记录中明确；不把文字标作AI生成，也不分发系统字体文件。文字可按已交付 PNG 使用，客户端使用无字底时应配置自身合法可用字体。

当前采用宿主内置 `image_gen`，目标配置为GPT Image2.5 Sunburst/max；工具未披露可核实实际型号或质量，逐图actualModel/actualQuality保持null。每个正式PNG均有来源SHA-256、切片/缩放/平移和Alpha记录。当前八张采用的源图位于 `designs/fx/full-game/`；旧落牌图被AI修正后的新源取代，仅保留其来源文字记录。

`qa.json`：35项文件、哈希、尺寸、真实Alpha和四角透明检查通过，24帧无重复，六条时序无lint警告，WebP解码时序与可见RGBA通过，Aseprite图集24帧RGBA回读通过。全部正式素材已实际检查深浅底、中文、阶段变化与边界。

`index.html` 提供本地播放与单图浏览，已检查静态链接和JS语法；浏览器交互未实测。真实游戏引擎的导入、牌局事件触发、播放观感与音效同步尚未运行，不能把资源验收写成客户端已接入。Doctor的 `python.path` 提醒机器有多个Python，实际脚本均显式使用隔离Python3.12运行，未用不确定的PATH解释器。
