# 全游戏补充 UI 域 v2

2026-10-26，用户要求继续到完整通用横屏 2D 麻将美术范围。本域补齐 UI25–UI32；全项目背景、其他角色、表情、花牌、道具与 FX 由其他域负责。本域不覆盖旧版 UI01–UI24 或旧包。

## 页面与状态合同

| ID | 页面 | 独立输出与状态 |
|---|---|---|
| UI25 | 装扮设置 | 桌布/牌背选择、选中与未选中、效果预览、应用操作 |
| UI26 | 角色详情 | 金带道童详情、表情预览、当前使用状态 |
| UI27 | 新手引导 | 第1步高亮选牌；第2步碰/杠/胡/过操作提示；第3步完成与重看 |
| UI28 | 公告详情 | 标题、日期、正文、返回；可选模块样例 |
| UI29 | 奖励领取 | 待领与已领两张独立状态，互斥领取按钮与回执 |
| UI30 | 成就收藏 | 已解锁、未解锁、进度；可选模块样例 |
| UI31 | 排行榜 | 前三、积分条目、自身位置；可选模块样例 |
| UI32 | 物品收藏 | 券、礼盒、徽章与槽位状态；可选模块样例 |

全部使用两张主风格参考，沿用玉绿、米白、薄暖金、云纹与道家 Q 版手绘。新界面以通用布局示例为边界；公告、成就、排行和收藏不代表已确认产品开启。示例积分、进度、物品数量均非真实账户数据。无价格、充值、现金或地方番型。

## 制作与检查

- `designs/ui/full-game/core/`：UI25、UI26、UI27 的三步，共5张独立整屏。
- `designs/ui/full-game/modules/`：UI28–UI32，奖励两态，共6张独立整屏。
- `designs/ui/full-game/component-sources/`：透明组件母版。
- `assets/ui/full-game/components/`：至少16款透明组件切片与清单。
- `prompts/full-game/ui/`：每次实际提示词。
- `work/full-game-ui/`：检查、预览与复现工具。

图像调用使用宿主内置 image_gen，目标配置为 GPT Image 2.5 Sunburst / max；工具未返回可核实 model/quality，实际字段保持 null。原生尺寸以实测为准。整屏中文字为美术稿；实际接入应使用原生文本与动态状态。

逐图 sidecar 核对图像 SHA-256、尺寸、实际参考、提示词、原生/派生说明和视觉检查。透明组件在浅深底检查边缘与状态。浏览器 file:// 已被限制，不重试、不绕行；本域采用文件、图像及静态检查，不宣称完成真实浏览器交互或客户端接入。

## 接入约束

UI25 中“预览中”表示正在查看该搭配，可与当前已用搭配相同；同款应用按幂等操作处理，保持当前方案。更换搭配并应用成功后，客户端再更新方案与成功回执。UI26 的已使用态不得同时启用使用按钮。UI27 的步骤图用于界面规范；碰、杠、胡仅在规则引擎判定可用时显示，不能依据示例图片推断规则或牌型。UI29 待领允许领取、已领禁用重复领取，回执由真实领取结果驱动。UI30–32 的计数、进度和排名由实际数据驱动。

复用旧域控件时直接引用 `assets/ui/manifest.json`，不复制或重新生成已经合适的58项组件。新增组件的九宫格/等比缩放策略由本域 manifest 指定；图标和中心装饰不得任意拉伸。

本域制作已完成，最终数量、哈希和检查见 `designs/ui/full-game/manifest.json` 与独立QA。主任务统一整合根 README、画廊和 v2 打包，本域不改旧 ZIP。
