## 基础素材包

1. **34 种基础牌面**：万/筒/条各 1—9，东南西北、中发白；每张符号数量、文字和方向逐张核对。另有统一牌背与空白牌胚。花牌为可选扩展，不混入当前规则。可用生成的无字牌胚加原生文字/符号确定性排版，但必须保持手绘底图来源，明确程序绘制牌面标记与生成底图区别，不能冒称全部为新模型生成。手牌、弃牌、副露和其他朝向的使用方案、选中/高亮/不可打状态记录清楚。
2. **对局组件**：独立牌桌背景、中央风位与回合牌、四座头像框、庄家/当前玩家/离线/托管标记、倒计时框、碰杠胡过按钮与提示、听牌提示、结算卡片。
3. **通用组件**：透明窗框、标题牌、内容卡片、主/次按钮及状态、页签、图标、滚动条、输入框、数字键盘、遮罩、提示气泡和未读角标；动态文字与底图分开。可伸缩项登记九宫格边距，不允许伸缩的人物/图标等比使用。
4. **角色配套**：现有迎宾道童修净后交付透明全身和头像；四个可区分座位头像（可以含道童），统一同套画法。用户未指定四套全身人物或动作动画，本轮确保 UI 所需角色素材齐全。

## 状态覆盖

所有正常入口均有返回/关闭去向。清单同时登记如下状态的图或组件来源：

- 房间：空座/满员、房主/成员、准备/未准备、等待开始、退出确认、解散发起/同意拒绝/进度/结束、加入失败。
- 对局：等待出牌、当前玩家、倒计时、庄家、离线/托管、碰杠胡过、多候选、听牌、胡牌/流局、单局继续与整场返回。
- 社交/记录：未读/已读、带附件/待领/已领取、在线/离线/忙碌、邀请已发、申请处理、空列表/无结果。
- 系统：加载、错误、掉线、重连中、恢复失败、匹配中/超时/取消；开关与按钮有正常/按下/选中/禁用映射。

## 交付目录与完成标准

- 独立页面与规范板：`designs/ui/full-suite/`；组件：`assets/ui/`；牌面：`assets/tiles/`；正式角色：`assets/characters/`。互斥 worker 子目录可保留，统一 manifest 汇总。
- 每张生成/AI 编辑图有提示词、实际参考输入、`.generation.json`、哈希、真实原生尺寸及视觉检查。未披露的实际型号/质量保持未确认。
- 派生切片保存 derivedFrom、operation、裁切坐标、尺寸、Alpha、锚点/边距、用途与来源记录。切片是派生资源，不声称为独立模型生成。
- 每页检查中文、控件层级、安全留白、四家牌区、风格一致；每张牌检查语义；透明资源在深浅底检查边缘，现有角色杂点必须修复。
- 提供可打开的本地画廊/索引、机器可读页面/状态/组件/牌面清单、来源记录与接入说明，打包到 `exports/`。画廊是浏览交付文件的工具，不等同实际麻将客户端。
- 全部合同项均有真实文件与检查结果才能写“全套完成”。具体缺项或未通过项保留未通过并修复，不能用旧首稿通过替代检查。

当前没有确定商城、充值、赛事、排行榜、俱乐部、背包或任务系统；它们可在用户提供具体产品需求后扩展，不为了本轮“全套”虚构经济与收费系统。没有客户端工程及服务端合同，因此本轮交付全套 UI 美术与接入资料，客户端代码/线上玩法验收另行界定。云端目的地未指定，继续本地保存。
