# 场景、桌面与标识接入

`assets/scenes/full-game/manifest.json`登记三张独立纯背景和两张新增空桌面。原有`assets/ui/gameplay/table-background.png`为第三套桌面。日景庭院、月夜水榭、室内茶室均为原生生成完整背景，没有从UI概念图抹字/裁出。实际宽1672，实际高940或941，接近16:9；按等比cover显示，勿拉伸。中心留出叠放角色与面板的空间，灯笼装饰不是动态UI文案。

场景为静态`baked_scene_mode`，不是可行走地图。没有碰撞、导航或出口数据需求。桌面提供参考可用区域多边形，不将它当作已经接入客户端的坐标合同；四家头像、弃牌、手牌和计时由独立资源与客户端排布。

`assets/branding/full-game/manifest.json`含月莲/竹韵两款牌背、无字标题牌、加载装饰、1024应用图标及512/192/128/64派生尺寸。牌背448×640，母图裁切原生内容透明补边，未放大细节。图标使用单独1254×1254母图，经Alpha清理和缩小导出1024，不使用图集小图放大。

所有标识都用真实RGBA，按直通Alpha导入。牌背、人物、图标和云角装饰等比显示；本组九宫格均为null。标题牌中央留空，用客户端原生文字显示正式名称；未编造商标或游戏名。加载小装饰可由客户端作为整体轻微旋转/脉冲；这种播放是图形变换，不是新绘逐帧动画。

主图集和应用图标母图的宿主输出存在少量低Alpha彩色杂点；正式导出只清理Alpha遮罩，未重绘RGB。操作阈值、柔边、裁切、透明补边、缩放和来源哈希均记录在逐图文件中。深浅底联系图为内部验收展示，不计入正式素材数量。

全组使用内置image_gen，实际附上两张用户指定的风格参考。配置目标GPT Image 2.5 Sunburst/max，工具未披露可核实的实际型号/质量，actualModel与actualQuality继续为null。
