# 通用与对局组件使用说明

本目录交付 58 项真实素材：通用 45 项、对局 13 项（其中包含一张独立 RGB 牌桌背景）。完整清单见 [manifest.json](manifest.json)，组件组合和交互状态绑定见 [component-compositions.json](component-compositions.json)。

## 来源与尺寸

绘制底图来自宿主内置 image_gen 的 6 张母版。窗框和背景原生 1672×941，三张基础母版原生 1254×1254，补充图标母版原生 1536×1024。目标尺寸不等于原生返回尺寸。

切片按实际图形边界裁切，未按平均网格硬切，未放大。每张资源都有相邻 .png.generation.json，记录 derivedFrom、SHA-256、源裁切坐标、真实尺寸、透明补边及状态处理。动态中文、数字、昵称和分数没有烘焙在底图内。

## 透明、状态和伸缩

- 透明素材先去除 Alpha≤8 的低透明杂点，以及不含 Alpha≥128 像素的孤立区域，再把 Alpha≥250 的主体归一到255；Alpha0处RGB置零。主体 Alpha≥128 像素零删失。深浅底联系表已检查。
- 窗框中心和头像框中心均为真实透明，不是浅底图片或棋盘格。半透明搜索镜片与选中光圈属于图形本身。
- 正常/按下/选中/禁用按钮为独立 PNG。后3态是基于正常皮肤的确定性亮度/色彩变化，几何和Alpha完全相同，不冒称新的模型生图。
- nineSlice 数组依次为左、上、右、下，单位是交付PNG像素；最小几何尺寸为左右边距和+1、上下边距和+1。窗框使用保守的 [200,200,200,200] 边距。主/次/对局按钮及所有状态仅允许横向九宫格伸缩，并锁定整体等比缩放后的高度，禁止纵向非等比拉伸圆珠。文字布局另需保证可读空间。
- 标题牌、提示气泡、圆头像框、图标、风位盘和结算卡片没有九宫格，等比显示；结算卡片顶底中央玉珠不能拉伸。标题顶部居中装饰与提示尖角不可横向拉伸。
- modal-shade.png 是8×8常量黑色Alpha144的运行时遮罩原语，非AI绘画。它只按全视口平铺或伸缩使用。

## 可复用组合

数字键盘使用同一 keypad-key.png 配合12个原生标签“1—9、清空、0、删除”；真实的3列4行位置和点击语义已在组合清单给出。六位房号输入用6个输入框。没有烘焙个人房号。

四座头像共用 avatar-frame.png，并配四个已交付头像；当前玩家使用独立光圈。风位、轮次、余牌、庄字、倒计时、听牌内容和碰/杠/胡/过标签都由客户端原生文字与标准牌面组装。组件映射不意味着已连接规则服务。

主/次按钮、页签、勾选、单选、开关、滑条、滚动条、输入、角标、加载遮罩、离线/托管、候选牌组和结果卡均有状态映射。离线与托管分别表示连接和代打状态，不能混作同一状态。

## 颜色语义

正分使用朱砂红 #B52F20，负分使用玉绿 #196448，零分与普通正文使用 #183D35。按钮上的米白文字为 #FFF4D9。禁用控件同时设置不可交互，不只降低透明度。

本包仅为美术组件与接入资料。实际模型与质量未由宿主披露，保持未确认；真实客户端和服务端接入尚未进行。


## 交付检查

58 项最终 PNG 通过文件完整性、尺寸、来源哈希和深浅底检查。缩放元数据修订未改变任何 PNG 哈希。独立牌桌背景与原生生成源像素完全一致，因 PNG 重编码移除了元数据，文件字节哈希不同；记录已准确区分像素一致与字节一致。

## 机械导出复现

`work/components/export_components.py` 负责裁切、透明清理与状态导出，`work/components/finalize_components.py` 同步最终缩放约束、使用清单与 QA 记录。重新导出后须实际检查深浅底联系表，再运行收尾脚本；不得把脚本写入的通过状态作为人工视觉验收的替代。
